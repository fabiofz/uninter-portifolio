## Publicação no GitHub Pages
- Usuário do GitHub: `fabiofz`
- Repositório sugerido: `portfolio_fabio`
- Repositório: `https://github.com/fabiofz/portfolio_fabio`
- URL esperada do GitHub Pages: `https://fabiofz.github.io/portfolio_fabio/`

1. Crie um repositório público chamado `portfolio_fabio` em `https://github.com/fabiofz`.
2. Envie `index.html`, `estilo.css` e `script.js` para a raiz do repositório.
3. Em **Settings > Pages**, habilite a publicação pela branch principal (`main`) e pela pasta raiz (`/root`).
4. Aguarde a publicação e teste o endereço gerado.
5. Use o link publicado e o link do repositório no documento de entrega.
