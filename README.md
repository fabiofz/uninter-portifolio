# Portfólio pessoal - Fábio Franzoni

Projeto acadêmico de Fundamentos da Programação Web.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro

## Estrutura
- `index.html`: página única com as quatro seções obrigatórias.
- `estilo.css`: estilos e responsividade, sem frameworks.
- `script.js`: menu responsivo, tema claro/escuro e validação do formulário.
- LinkedIn: `https://www.linkedin.com/in/fabio-franzoni-dev`
- O portfólio inclui uma síntese profissional, competências técnicas e os 10 certificados públicos visíveis no perfil do LinkedIn.

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub com um nome contendo seu nome, por exemplo `portfolio-fabio-franzoni`.
2. Envie `index.html`, `estilo.css` e `script.js` para a raiz do repositório.
3. Em **Settings > Pages**, habilite a publicação pela branch principal (`main`) e pela pasta raiz (`/root`).
4. Aguarde a publicação e teste o endereço gerado.
5. Use o link publicado e o link do repositório no documento de entrega.
